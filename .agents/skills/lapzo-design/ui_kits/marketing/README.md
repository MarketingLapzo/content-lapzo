# Marketing UI Kit — Lapzo

Recreación del sitio web público de Lapzo: landing page con hero, módulos, casos de éxito, social proof y footer.

## Pantallas

- **Landing** (`index.html`) — hero con propuesta de valor, los 6 módulos, casos de éxito con datos (Mazda, Rotoplas, Tecmilenio, Execon), social proof por sector, sección de Lapzo.IA, footer con co-branding Tecmilenio.

## Estructura

Sigue los **3 pilares marcarios** del manual:
1. **Innovadora** — sección de IA + cohete + lapzi.IA
2. **Confiable** — banda de logos de clientes + casos con datos reales
3. **Experta en talento** — módulos con iconos + descripción de impacto

## Componentes

- `NavBar` — sticky transparente sobre hero, sólida al hacer scroll
- `Hero` — H1 Space Grotesk + sub Poppins + dos CTAs + arrow decorativo + Lapzi
- `ModuleGrid` — los 6 módulos con icono propio
- `CaseCard` — estructura `[dato] + [cliente] + [verbo de acción]`
- `IAStrip` — banda con degradado violeta + Lapzi IA + capacidades
- `Footer` — dark `#14142A` con sitemap, idiomas y co-brand
